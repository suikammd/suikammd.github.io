Setting Up a Local HTTPS Server
2020-10-09|

  1. Generate a certificate
    (1) Generate an RSA key: openssl genrsa -des3 -out server.key 1024
    (2) Remove the passphrase protecting the key file: openssl rsa -in server.key -out server.key
    (3) Generate the CSR for the CA: openssl req -new -key server.key -out server.csr
    (4) Self-sign the certificate: openssl x509 -req -days 1024 -in server.csr -signkey server.key -out server.crt
    (5) cat server.crt server.key > server.pem

  2. Python script

  3. In macOS Keychain, move the certificate to the System keychain and set its SSL trust setting to Always Trust.
