Understanding How Go Passes Slices to Functions
2020-11-11|

When I first started learning Go, what puzzled me most was passing slices to functions: had the slice changed or not? I recently discovered that some of my colleagues were not clear about this either, so I decided to take a closer look at whether modifying a slice passed to a function changes the original slice.

Slice structure

I’ll start with the structure of a slice. As you can see, a slice is actually backed by an array.

Function passing

One point needs to be clear: Go uses pass-by-value, meaning it copies values.
