Setting Up a Local HTTPS Server 2020-10-09|https

  1. Generate a certificate
    (1) Generate an RSA key: openssl genrsa -des3 -out server.key 1024
    (2) Remove the passphrase protecting the key file: openssl rsa -in server.key -out server.key
    (3) Generate the CSR for the CA: openssl req -new -key server.key -out server.csr
    (4) Self-sign the certificate: openssl x509 -req -days 1024 -in server.csr -signkey server.key -out server.crt
    (5) cat server.crt server.key > server.pem

Cross-Compilation for AArch64 2019-04-27|petalinux

Objective

In the article Porting Linux to the Xilinx ZCU104 with PetaLinux (FFmpeg), I explained how to set up an operating system on the ZCU104 board. To transfer images captured by a Hikvision camera to the DDR memory of the ZCU104 board’s PS, I wrote code based on libavutil, libavformat, and libavcodec. It automatically extracts keyframes from a video stream and saves them in JPG format (they will later need to be converted to YUV format).

An elegant approach is to compile the code on another platform and run only the release build on the ZCU104. Observant readers may have noticed that the article about setting up the operating system did not install gcc. I cross-compiled the code on a GCE virtual machine so that it can run on the operating system installed on the ZCU104, whose hardware architecture is AArch64.

The goal is now clear: cross-compile code on x86_64 so that it can run on AArch64. Since I have already installed the FFmpeg libraries in PetaLinux, all libraries can be dynamically linked during compilation.

  1. An Ubuntu virtual machine. I used a free VM from Google Cloud Engine, located in Taiwan for better speed, with 15 GB of RAM, 4 vCPUs, and a 60 GB disk. Elasticsearch Rollup 2018-10-12|elasticsearch

Log data is redundant and voluminous. Elasticsearch’s Rollup feature can preprocess data in advance, reducing the amount of storage space required.

A First Look at the Basic Features

Rollup is included in the Elasticsearch X-Pack. The Elasticsearch version used in this article is 7.2.0. This article mainly discusses the start and search functions of the Rollup API, as well as how Rollup searches differ from regular searches.

  1. Basic Rollup Usage

    For details on creating, deleting, viewing, starting, and stopping Rollup jobs, see the official Elasticsearch documentation.

  2. Rollup Start

    After a Rollup job is created, you must call start before it begins running. It is stopped by default.

    This request is handled by the taskOperation of TransportStartRollupAction, which then calls start in RollupJobTask. Next, the RollupIndexer implementation ClientRollupPageManager performs the search and bulk operations.
