Saving Money on AWS
2019-05-29|

Objective

Building PetaLinux requires at least four CPU cores. I had run out of GCE virtual machine resources, and AWS compute resources are very expensive. Fortunately, I still had $100 in free credit. So I decided to use a very hacky approach (because I am not skilled enough to do better): when preparing to build, stop the AWS instance, upgrade it from t2.micro (free on AWS) to t2.xlarge, then start it and send its public IP address to a Telegram bot. Once the build is complete, stop the instance, downgrade it, and start it again.

I also want the Telegram bot to send me billing information on a schedule, since $100 can disappear in the blink of an eye.

Communication

At first, I did not consider that connecting to the instance over SSH requires its public IP address, so the script ended as soon as the instance was upgraded and restarted. After considering the IP address issue, I decided to send it to a Telegram bot. The approach I ultimately adopted was to register an object on the server through RPC and expose the service using the object’s type name. The client calls these methods remotely. The public IP address is sent to the Telegram bot after the upgrade and reboot are complete. Of course, RPC is not necessary; I could send every request through the Telegram bot instead, which would look nicer.

  1. RPC

    Use Go’s net/rpc package.

  2. Telegram Bot

    See Using the Telegram Bot.

    • Send /newbot to Telegram’s BotFather.
    • Enter a bot name ending in bot.
    • Get the bot token returned by BotFather.
