Cross-Compilation for AArch64
2019-04-27|

Objective

In the article Porting Linux to the Xilinx ZCU104 with PetaLinux (FFmpeg), I explained how to set up an operating system on the ZCU104 board. To transfer images captured by a Hikvision camera to the DDR memory of the ZCU104 board’s PS, I wrote code based on libavutil, libavformat, and libavcodec. It automatically extracts keyframes from a video stream and saves them in JPG format (they will later need to be converted to YUV format).

An elegant approach is to compile the code on another platform and run only the release build on the ZCU104. Observant readers may have noticed that the article about setting up the operating system did not install gcc. I cross-compiled the code on a GCE virtual machine so that it can run on the operating system installed on the ZCU104, whose hardware architecture is AArch64.

The goal is now clear: cross-compile code on x86_64 so that it can run on AArch64. Since I have already installed the FFmpeg libraries in PetaLinux, all libraries can be dynamically linked during compilation.

Steps

  1. Install the cross-compilation tools
    You could use the Linaro cross-compilation toolchain. You need to download both the cross-compilation tools and the cross-compilation libraries. The latter contain the libraries needed to link basic programs.

    If you installed the operating system by following my article Porting Linux to the Xilinx ZCU104 with PetaLinux (FFmpeg), you do not need to download the cross-compilation tools, but you still need the cross-compilation libraries. Then run source ./settings.sh in the petalinux installation directory. I used aarch64-linux-gnu-gcc as the cross-compiler; run aarch64-linux-gnu-gcc --version to check whether it is installed.

  2. Install cross-platform dependency libraries

    Rename the downloaded cross-compilation library directory sysroot-glibc-linaro-2.25-2018.05-aarch64-linux-gnu to sysroot. The compiler searches the usr directory under sysroot.

    To compile the code on an x86_64 Linux platform, use gcc -o xxx xxx.c -lavutil -lavformat -lavcodec -lz -lpthread; therefore, the corresponding libraries, such as FFmpeg, must be cross-compiled. To make sure we do not miss any required libraries, we can directly run the cross-compilation command aarch64-linux-gnu-gcc --sysroot=/path/to/sysroot -o xxx xxx.c -lavutil -lavformat -lavcodec -lz -lpthread, inspect the errors to see which libraries are missing, and then cross-compile those libraries.

    If you have installed PetaLinux, you can copy the appropriate libraries from <project_dir>/build/tmp/sysroots-components/aarch64 into the lib and include directories under usr in your sysroot path.

  3. Cross-compile

    • –sysroot: The compiler automatically searches the lib and include directories under usr within the specified sysroot path.

Summary

In summary, cross-compilation involves two steps: configure the appropriate cross-compiler, then specify its search paths so it can find the required libraries and header files.

To save time, I used a fairly naive approach. If you know a better way, please open an issue on my GitHub, suikammd.
