Porting Linux to the Xilinx ZCU104 with PetaLinux (FFmpeg)
2019-04-24|

PetaLinux is an embedded Linux development tool from Xilinx. This article is based on Xilinx’s official PetaLinux Tools Documentation. I also describe some of the errors I encountered during the build, in the hope of saving you time. Please go easy on me with your feedback.

(If you run into any problems, please open an issue on my GitHub repository, suikammd. Thanks! I still have not set up a comments section—procrastination =.=)

Preparing the Environment

  1. An Ubuntu virtual machine. I used a free VM from Google Cloud Engine, located in Taiwan for better speed, with 15 GB of RAM, 4 vCPUs, and a 60 GB disk. (Do not struggle with VMware on your own; subsequent PetaLinux builds require bypassing network restrictions, which is painfully slow. GCE also lets you experiment freely. Thanks, Google!)
  2. The PetaLinux SDK Installer and ZCU104 BSP file. Both files can be downloaded from file download. I downloaded version 2018.1 of both. If you want a later version, check whether your board is supported. The SDK installer and BSP versions must match!

Installation Steps

  1. GCE account setup: I will not go into detail about applying for a GCE account. When creating your VM, remember to select Allow HTTP traffic and Allow HTTPS traffic in the firewall settings, and add your public key under SSH Keys. This will automatically generate an external IP address for the VM, and you can then connect over SSH and start using it.

While writing a DMA driver, I discovered an easier verification method that does not require copying the data to an SD card. Run petalinux-boot --qemu --kernel on the command line to test using the emulator. The specific tests are the same as those described above.
