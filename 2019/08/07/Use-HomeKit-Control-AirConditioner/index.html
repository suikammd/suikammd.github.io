Using a Raspberry Pi and HomeKit to Control an Air Conditioner
2019-08-07|

Every day when I get home or before going to bed, I can never find the air-conditioner remote ==. After much trial and error, I finally thought of using HomeKit to control my air conditioner. By connecting an infrared transmitter to a Raspberry Pi, I can control the air conditioner directly from my phone! (And I am not going to lose my phone ʕ •ᴥ•ʔ)

Prerequisites

  • Raspberry Pi + infrared transmitter (receiver)
  • Female-to-female Dupont wires
  • iPhone with the Home app installed

Setup

  1. Configure the Raspberry Pi:
    • Connect the infrared transmitter to gpio17 (BCM).
    • Add dtoverlay=lirc-rpi,gpio_in_pin=18,gpio_out_pin=17 to /boot/config.txt.
    • Install and configure Lirc.
  2. Configure lircd:
    • Place the configuration file air.lircd.conf in the /etc/lirc/lircd.conf.d directory (make sure the file extension is .conf).
    • Restart lirc: sudo systemctl restart lircd.service.
  3. Restart the program:
    • Place ac.conf in /etc/supervisor/conf.d.
    • Use the default PIN 23333333 to pair the accessory with HomeKit.

See the AirConditioner-HomeKit project.
